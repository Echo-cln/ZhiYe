# 知页页面与交互地图

| 页面 | 入口 | 核心交互 | 数据依赖 |
|---|---|---|---|
| 首页 | 底部导航 | 主题筛选、媒体筛选、下拉刷新、搜索、打开文章、收藏 | Room + RSS |
| 全部议题 | 首页「全部议题」 | 六类主题入口，进入对应筛选结果 | Room 查询 |
| 媒体来源 | 首页「媒体目录」 | 查看媒体接入状态、打开官网、按媒体查看报道 | NewsSource + Room |
| 新闻详情 | 首页/搜索/收藏 | 查看摘要、阅读原文、分享、收藏、阅读进度续读 | Room |
| 搜索 | 首页搜索 | 标题/摘要/来源检索，组合主题和媒体筛选 | Room |
| 我的收藏 | 底部导航/个人中心 | 打开文章、取消收藏 | Room |
| 阅读历史 | 个人中心 | 继续阅读、查看进度、清空历史 | Room |
| 我的 | 底部导航 | 登录注册、本地新闻管理、阅读设置 | Session + Room |
| 阅读设置 | 我的 | 调整正文大小和行间距，实时预览 | SharedPreferences |
| 本地新闻管理 | 我的 | 新增、编辑、删除 | Room CRUD |
| 登录/注册 | 我的 | 本地账户注册、登录、退出 | UserDao |
| 平板双栏 | 首页 | 左侧新闻列表，右侧详情预览 | Room |

## 视觉规则
- 纯白背景，深灰正文，蓝色作为克制的交互强调色。
- 正文采用系统无衬线字体；新闻标题控制字号，不使用大字报式排版。
- 细分隔线、适度留白、轻量控件，避免密集卡片和装饰性大色块。
- 新闻图片服务于报道，不做装饰性大面积色块。
