| 页面 | 入口 | 核心交互 | 数据依赖 |
|---|---|---|---|
| 首页 | 底部导航 | 主题筛选、媒体筛选、下拉刷新、搜索、点开文章、收藏 | Room + RSS |
| 议题 | 底部导航 | 六类主题入口 | Room 查询 |
| 媒体 | 底部导航 | 查看媒体接入方式、打开官网、按媒体查看报道 | NewsSource + Room |
| 新闻详情 | 首页/搜索/收藏 | 阅读摘要、收藏、打开原文 | Room |
| 搜索 | 首页搜索 | 标题/摘要/来源检索，可带主题或媒体过滤 | Room |
| 我的 | 底部导航 | 登录注册、收藏、历史、本地新闻管理、设置 | Session + Room |
| 我的收藏 | 我的 | 打开、取消收藏 | Room |
| 阅读历史 | 我的 | 打开历史文章、清空历史 | Room |
| 本地新闻管理 | 我的 | 新增、编辑、删除 | Room CRUD |
| 登录/注册 | 我的 | 本地账户注册、登录、退出 | UserDao |
| 设置 | 我的 | 清空历史、退出账户、关于 | Room + Session |
| 平板双栏 | 首页 | 左侧新闻列表，右侧预览详情 | Room |

## 视觉规则
- 暖白纸感背景，黑色正文，酒红色作为少量强调。
- 新闻标题采用衬线字体，正文优先可读性。
- 细分隔线与充足留白，避免密集卡片和高饱和科技色。
- 新闻图片服务于报道，不做装饰性大面积色块。
